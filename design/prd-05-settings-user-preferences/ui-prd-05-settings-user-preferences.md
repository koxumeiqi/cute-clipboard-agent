# 设置与用户偏好 - 界面设计

## 页面 / 窗口 / 入口
- 设置窗口由桌宠右键菜单打开。
- Tauri 窗口 label 为 `settings`，加载 `settings.html`。

## 组件结构
- `SettingsWindow`：负责加载、保存和状态反馈。
- 容量选择：三段式按钮 `10 / 20 / 50`。
- 记录控制：文本记录、图片记录、暂停记录。
- 桌宠行为：待机动画、自动移动。
- 启动与隐私：开机启动、本地持久化。

## 状态
- 加载中：显示加载状态。
- 就绪：显示表单。
- 保存中：禁用控件并显示保存中。
- 已保存：显示短暂成功反馈。
- 错误：显示错误文案，保留上一次成功设置。
- 禁用 / 未授权：开机启动底层未接入，但字段仍可保存为偏好。

## 交互
- 用户点击容量按钮立即保存。
- 用户切换开关立即保存。
- 保存失败时控件回到上一次成功状态。
- 窗口右上角提供关闭按钮。

## 视觉与可访问性规划
- 使用紧凑设置面板布局，适合桌面工具反复访问。
- 控件有明确 label、aria 状态和键盘可聚焦按钮。
- 使用 lucide 图标辅助分组，不用装饰性大卡片。

## UI BDD 场景
- Given 设置加载成功，When 用户点击 10 条容量，Then 10 条按钮被选中并显示已保存。
- Given 设置加载成功，When 用户关闭文本记录，Then 文本记录开关显示关闭。
- Given 保存失败，When 用户切换任意开关，Then 页面显示错误并恢复原值。

## E2E 验证计划
### 自动化范围
- Vite 页面加载设置窗口。
- Mock Tauri invoke 验证加载、切换容量、切换暂停记录、错误恢复。

### 人工范围
- 在 Tauri 桌面窗口打开设置页。
- 切换待机动画后观察桌宠动画状态。
- 重启应用后确认设置保留。

### 环境要求
- Windows Tauri dev 环境。
- 可访问本地 WebView2。

### 需要捕获的证据
- 设置窗口截图。
- 保存成功和失败状态。
- 历史容量变化后的历史窗口数量。

## 人工验证清单
- 从桌宠菜单打开设置窗口。
- 历史容量 10/20/50 可切换并保存。
- 关闭文本记录后复制文本不入栈。
- 关闭图片记录后复制图片不入栈。
- 打开暂停记录后复制任意内容不入栈。
- 关闭待机动画后桌宠停止上下浮动。
- 重启后设置值仍然存在。
