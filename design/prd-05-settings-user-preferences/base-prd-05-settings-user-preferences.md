# 设置与用户偏好 - 基础设计

## 来源
- PRD：`docs/prd/05-设置与用户偏好.md`
- 分支：`codex/prd-05-settings-user-preferences`
- 相关模块：`features/settings`、`windows/settings`、`settings`、`clipboard`、`history`、`events`

## 目标
- 提供统一 `AppSettings` 读取和保存入口。
- 让用户配置历史容量、文本记录、图片记录、待机动画、自动移动、开机启动、本地持久化和暂停记录。
- 设置保存后立即影响剪贴板记录、历史裁剪和桌宠行为，并发出统一设置更新事件。

## 非目标
- 不实现敏感内容识别、忽略指定应用、自动清理周期、模型或 MCP 配置。
- 不接入真实系统开机启动注册，只保留可持久化字段和应用边界。
- 不改变 Agent Bridge 权限模型。

## 共享领域模型
- `AppSettings` 聚合剪贴板、历史、桌宠和生命周期偏好。
- `UpdateAppSettingsRequest` 所有字段均可选，用于局部更新。
- 历史容量仅允许 `10`、`20`、`50`。

## 公共契约
### 命令 / API
- `get_app_settings() -> AppSettings`
- `update_app_settings(request: UpdateAppSettingsRequest) -> AppSettings`

### 事件
- `settings.updated`：设置保存成功后发送，payload 只包含设置值和时间，不包含剪贴板完整内容。
- `settings.clipboard_recording_paused`：暂停记录从 false 变为 true 时发送。
- `settings.clipboard_recording_resumed`：暂停记录从 true 变为 false 时发送。

### 权限
- 设置读写只操作本地配置和本地 SQLite 历史设置，不请求外部网络权限。

### 持久化
- 复用现有 pet JSON、clipboard recording JSON 和 history SQLite settings。
- `launchAtStartup` 作为本地 JSON 字段持久化，底层注册由后续生命周期模块实现。

## UI-App 集成契约
### UI 调用
- 设置窗口加载时调用 `get_app_settings`。
- 用户修改控件后调用 `update_app_settings`，保存成功后刷新本地状态。

### 应用 / 原生响应
- `recordText`、`recordImage`、`recordingPaused` 更新剪贴板记录 store。
- `historyCapacity`、`persistenceEnabled` 更新历史 store，并触发容量裁剪。
- `idleAnimationEnabled`、`autoMoveEnabled` 更新桌宠设置；待机动画由桌宠窗口下次读取或事件订阅刷新。

### 事件订阅
- MVP 设置页不依赖事件回填；保存返回值作为 UI 真相。

### 状态同步
- 保存时 UI 进入 `saving`。
- 保存成功显示 `saved`。
- 保存失败保留原设置并显示错误。

### 错误映射
- 容量非法映射为设置保存失败。
- 读写失败统一显示“设置保存失败，请稍后重试”。

### 权限边界
- 设置事件不携带历史项内容、文本正文或图片字节。

## 集成边界
- 设置模块负责聚合配置状态，不直接读取系统剪贴板。
- 历史模块负责容量裁剪和持久化策略。
- 剪贴板模块负责根据记录类型和暂停状态决定是否入栈。
- 生命周期模块后续负责真实开机启动注册。

## BDD 场景
### 场景：查看当前设置
前置条件：应用已启动。
触发动作：用户打开设置窗口。
预期结果：窗口显示当前容量、记录类型、桌宠行为、开机启动、本地持久化和暂停记录状态。

### 场景：保存历史容量
前置条件：历史中已有超过 10 条记录。
触发动作：用户将容量改为 10 并保存。
预期结果：设置保存成功，历史栈裁剪到 10 条。

### 场景：暂停剪贴板记录
前置条件：记录处于开启状态。
触发动作：用户打开暂停记录开关并保存。
预期结果：后续新剪贴板内容不入栈，并发送暂停事件。

### 场景：关闭文本记录
前置条件：文本记录处于开启状态。
触发动作：用户关闭文本记录并保存。
预期结果：后续复制文本或 emoji 不入栈，图片记录不受影响。

## 风险
- 真实开机启动注册不在本 PRD 范围，设置页需要明确表现为偏好保存。
- 现有中文文件存在编码显示问题，新增文档保持 UTF-8。

## 未决问题
- 关闭本地持久化是否清理既有历史仍需产品确认；本实现保持已有行为：不写入新历史，但不主动清空现有记录。
