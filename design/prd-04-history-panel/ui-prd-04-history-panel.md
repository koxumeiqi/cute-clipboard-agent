# 剪贴板历史面板 - 界面设计

## 页面 / 窗口 / 入口
- `apps/desktop/src/windows/history/main.tsx` 挂载独立历史窗口。
- `HistoryWindow` 是窗口根组件。
- 桌宠双击和后续托盘入口通过 `open_history_panel` 打开该窗口。

## 组件结构
- `HistoryWindow`
  - 顶部标题区：标题、记录数量、刷新按钮、关闭按钮。
  - 内容区：加载提示、错误提示、空状态、历史列表。
  - 历史项：类型标识、文本/emoji 预览或图片缩略图、时间、恢复成功状态、删除按钮。
  - 底部操作区：容量信息、清空历史按钮。

## 状态
- 加载中：显示读取提示，避免空白窗口。
- 就绪：展示列表和可操作按钮。
- 空状态：显示“暂无剪贴板历史”。
- 错误：显示失败提示和刷新入口，不清空已有快照。
- 禁用 / 未授权：MVP 无单独授权态；命令失败统一进入错误态。

## 交互
- 点击刷新按钮重新读取历史。
- 点击关闭按钮关闭历史窗口。
- 点击历史项主区域恢复内容到系统剪贴板。
- 点击删除按钮只删除，不触发恢复。
- 点击清空历史按钮清空全部；无记录时按钮禁用。
- 恢复成功后在该项旁显示短暂成功图标与文案。

## 视觉与可访问性规则
- 列表项高度稳定，文本预览不撑开布局。
- 图片缩略图使用固定尺寸，缺失缩略图时退回图片占位。
- 图标按钮必须有 `aria-label`。
- 删除按钮与列表项恢复操作分离，避免误触。
- 文案使用中文，不展示乱码。

## UI BDD 场景
- Given 历史 API 返回 2 条记录，When 打开窗口，Then 展示标题、数量和两条记录。
- Given 历史 API 返回空列表，When 打开窗口，Then 展示空状态且清空按钮禁用。
- Given 图片记录含 `thumbnailPath`，When 打开窗口，Then 展示图片缩略图。
- Given 用户点击删除按钮，When 删除成功，Then 调用删除 API 且记录从列表移除。
- Given 用户点击历史项，When 恢复成功，Then 展示恢复成功反馈。

## E2E 验证计划

### 自动化范围
- 使用 Vitest + Testing Library 覆盖组件状态、恢复、删除、清空和图片预览。
- 使用前端 build 验证 history 窗口入口可编译。
- 使用 Rust 测试覆盖 history store 与图片恢复辅助逻辑。

### 人工范围
- 在 Windows Tauri 开发窗口中双击桌宠打开历史面板。
- 手工复制文本、emoji、图片后确认列表预览。
- 点击历史项后用系统剪贴板粘贴验证恢复结果。
- 删除单条和清空全部后确认 UI 与本地历史一致。

### 环境要求
- Windows 桌面环境。
- Tauri dev 或 debug 可执行程序。
- 系统剪贴板可读写。

### 需要捕获的证据
- 历史窗口截图。
- 文本/emoji 粘贴结果。
- 图片粘贴结果或目标应用截图。
- 测试命令输出。
