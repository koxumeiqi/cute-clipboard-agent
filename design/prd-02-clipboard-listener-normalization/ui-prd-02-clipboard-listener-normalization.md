# 剪贴板监听与内容归一化 - 界面设计

## 页面 / 窗口 / 入口
- 无直接 UI。
- 用户可见效果体现在后续历史面板：复制文本、emoji、图片后出现历史项；暂停或禁用类型时不新增。
- 设置页后续接入 `ClipboardRecordingSettings` 控制暂停、文本记录、图片记录。

## 组件结构
- 本单元不新增 React 组件。
- 前端只新增共享 API 封装，供后续设置页/历史面板调用。

## 状态
- 加载中：读取剪贴板设置命令未返回。
- 就绪：设置读取成功，监听服务按配置工作。
- 空状态：没有新剪贴板条目时不显示额外 UI。
- 错误：读取失败只记录事件，不打断用户当前工作。
- 禁用 / 未授权：`paused=true` 或类型开关关闭时忽略对应变化。

## 交互
- 暂停记录：设置页或宠物菜单调用 `set_recording_paused`。
- 类型开关：设置页调用 `update_clipboard_recording_settings`。
- 恢复历史：历史面板写回前调用 `suppress_next_clipboard_hash`。

## 视觉与可访问性规划
- 本单元无新增可视界面。
- 后续 UI 控件应使用明确标签和二元开关，不用弹窗打断剪贴板读取失败。

## UI BDD 场景
- 场景：用户暂停记录后复制内容，历史面板不出现新增项。
- 场景：用户关闭图片记录后复制图片，历史面板不出现新增图片项。
- 场景：用户从历史面板恢复旧内容，历史列表不出现重复新项。

## E2E 验证计划
### 自动化范围
- 通过 Rust 单元测试验证归一化、过滤、去重和抑制。
- 通过 TypeScript 契约测试验证命令和事件名称。

### 人工范围
- Windows 桌面复制文本、emoji、图片后观察历史模块接入结果。
- 暂停记录、关闭图片记录、历史写回抑制需在完整 Tauri 应用内验证。

### 环境要求
- Windows 桌面会话。
- Tauri 应用可运行，系统剪贴板可访问。

### 需要捕获的证据
- 测试命令输出。
- 手工验证时的操作步骤和实际结果。

## 人工验证清单
- 复制普通文本，历史新增一条文本记录。
- 复制 emoji，预览保留 emoji。
- 复制图片，历史新增一条图片记录。
- 开启暂停记录后复制内容，历史不新增。
- 关闭图片记录后复制图片，历史不新增。
- 从历史恢复内容，不新增重复历史。
