# 01-桌宠入口与桌面交互

## 1. 单元概览

- PRD ID: 01
- 标题: 桌宠入口与桌面交互
- 状态: draft
- 来源 MRD: `docs/mrd.md`
- 是否开发单元: 是
- 核心交付: 常驻桌面的透明桌宠窗口、拖拽、双击打开历史、右键快捷菜单、待机动画与自动移动控制。

## 2. 背景与目标约束

- 服务的产品目标: 提供常驻桌面的可爱入口，快速打开剪贴板历史。
- 目标用户/角色: 长时间在 Windows 桌面工作的剪贴板高频用户。
- 关联核心场景: 用户复制内容后，通过双击桌宠在 3 秒内打开历史面板并找回内容。
- 不包含的 MRD 范围: 不实现多角色桌宠、完整 Agent 对话、跨平台适配。
- 关键成功口径: 桌宠可见、可拖动、双击响应稳定，不干扰用户桌面操作。

## 3. 范围

### 3.1 包含范围

- 透明、无边框桌宠窗口。
- 桌宠默认出现在 Windows 桌面可见区域。
- 鼠标拖拽移动桌宠。
- 保存并恢复桌宠位置。
- 双击桌宠打开或聚焦剪贴板历史面板。
- 右键桌宠打开快捷菜单。
- 待机动画开关。
- 自动移动开关，MVP 可默认关闭。

### 3.2 不包含范围

- 多角色桌宠。
- Live2D 或复杂动画资产制作。
- 边缘吸附、避让窗口等高级行为。
- Agent 主动提醒气泡。

### 3.3 边界说明

桌宠只负责入口和窗口交互，不直接读取剪贴板、不直接操作历史数据。历史展示、恢复和清理由历史面板及存储模块负责。

## 4. 用户与场景

- 前置条件: 应用已启动，用户已完成或跳过允许范围内的首次告知流程。
- 触发条件: 用户看到桌宠并进行拖拽、双击或右键操作。
- 核心用户故事: 作为用户，我希望桌宠常驻桌面且可以移动，这样我能用轻量入口快速打开剪贴板历史。

## 5. 功能需求

| 编号 | 需求 | 优先级 | 来源 | 备注 |
|---|---|---|---|---|
| PET-01 | 桌宠以透明无边框窗口展示 | P0 | MRD 2.1 | 默认可见 |
| PET-02 | 支持鼠标拖拽并实时更新窗口位置 | P0 | MRD 2.1、5.3 | 拖拽过程应流畅 |
| PET-03 | 拖拽结束后保存桌宠位置 | P0 | MRD 5.3 | 重启后恢复 |
| PET-04 | 双击桌宠触发打开历史面板 | P0 | MRD 2.1、5.2 | 触发 `pet.double_clicked` |
| PET-05 | 右键桌宠展示快捷菜单 | P1 | MRD 2.1 | 菜单项与托盘保持一致 |
| PET-06 | 支持待机动画开关 | P1 | MRD 2.1、2.5 | MVP 可用简单动画 |
| PET-07 | 支持自动移动开关 | P2 | MRD 2.1、2.5 | 默认关闭更稳妥 |

## 6. 流程与状态

- 主流程: 应用启动 -> 读取桌宠配置 -> 创建桌宠窗口 -> 用户双击 -> 发送打开面板事件。
- 分支流程: 用户拖拽 -> 进入拖拽状态 -> 跟随鼠标移动 -> 释放 -> 保存位置。
- 异常流程: 恢复位置超出可见屏幕时，应回退到默认可见区域。
- 状态变化: `idle` -> `dragging` -> `idle`；`idle` -> `opening_panel` -> `idle`。

## 7. 依赖关系

### 7.1 上游依赖

- 设置与用户偏好提供位置、动画、自动移动配置。
- 事件总线提供 `pet.double_clicked` 等事件。

### 7.2 下游影响

- 历史面板依赖桌宠双击入口。
- 系统托盘复用快捷菜单命令。

### 7.3 共享实体

- `AppSettings.pet`
- `PetPosition`
- `AppEvent`

### 7.4 相关 PRD

- 04-剪贴板历史面板
- 05-设置与用户偏好
- 06-系统托盘与应用生命周期
- 08-事件总线与智能体桥接预留

## 8. 数据、事件与接口

- 涉及数据实体: 桌宠位置、桌宠行为设置。
- 关键字段: `position.x`、`position.y`、`idleAnimationEnabled`、`autoMoveEnabled`、`alwaysOnTop`。
- 核心事件: `pet.double_clicked`、`pet.drag_started`、`pet.drag_ended`、`pet.idle_started`、`pet.idle_moved`。
- API / 服务需求: 窗口创建、窗口移动、窗口置顶、保存设置。

## 9. UX / 页面 / 交互要求

- 页面或界面: 桌宠透明窗口、右键快捷菜单。
- 用户操作: 拖拽、双击、右键。
- 反馈机制: 拖拽时位置跟手；双击后面板打开；菜单命令执行后状态同步。
- 可访问性或易用性要求: 桌宠不能默认出现在屏幕外；自动移动不能频繁打扰用户。

## 11. 风险与未决问题

### 11.1 风险

- 透明窗口、置顶和桌面可见区域在 Windows 多屏环境下可能表现不一致。

### 11.2 未决问题

- MVP 桌宠形象使用静态图片、CSS 动画、Canvas、Lottie 还是 Live2D 待确认。
