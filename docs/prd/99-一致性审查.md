## 覆盖性检查

MRD 中明确需要开发的 MVP 能力已覆盖：桌宠展示、拖拽、双击、剪贴板文本/emoji/图片监听、最近 20 条历史栈、历史面板、点击恢复、删除、清空、暂停记录、本地配置、隐私告知、Agent Bridge 空实现。

V1/V2/V3 中的搜索、筛选、Agent 分析、OCR、MCP、主动提醒等未作为 MVP PRD 拆出，只在相关 PRD 的不包含范围或预留说明中体现，符合“只拆开发单元”的规则。

## 非开发单元过滤检查

未生成“产品基础与范围”“目标用户”“产品目标”“成功指标”“版本规划”等独立 PRD。相关信息已进入索引的全局背景摘要和各 PRD 的背景与目标约束。

核心共享实体包括 `ClipboardItem`、`AppSettings`、`PrivacyState`、`AppEvent`、`AgentContext`。各 PRD 均标明上游依赖和下游影响。需要在技术设计中进一步统一 TypeScript 与 Rust 侧类型定义。
